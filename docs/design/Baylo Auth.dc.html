Build notes — auth
Methods. Google and email + password. Phone is gone as a login method, so the SMS code screen went with it — nothing else routed to it.

Sheet geometry, at rest. Sheet is bottom-anchored with top radius 28 and margin-top −28, so visible band = declared band − 28. 4a / 4d / 4e: band 281 → 253 visible = 30.0%. 4f: same 281. Sheet takes flex:1 1 auto.

4b, five fields at rest. Band drops to 200 → 172 visible (20%). Five 56px fields, the declaration line, the button and the footer need 564; the flexed sheet gives 648. Video yields the height, per your own reasoning for 30% over 45%.

4c, five fields with the IME up. IME 358 leaves 486. Content measures 476 — five fields (5 × 56 + 4 × 9 = 316), header 32, button 52, declaration 16, padding 36. That does not leave room for a video sliver, so the sheet takes the full 486 with square top corners and the video is covered, still playing, and returns when the IME dismisses. Column: 486 + 358 = 844 exactly, box-sizing border-box, no negative margin. If a device reports IME > 380, scroll the field stack and pin the button to the sheet bottom.

Date of birth. A tappable field opening the native date picker, never a typed field and never a checkbox — no keyboard, and the recorded value is a real date. Default the picker to 18 years ago so the common case is one scroll. Validate on submit only: never surface an age error while the picker is open.

Rejection. Blocking, at submission. Shows the date entered, the computed age and the eligible-from date so the user can tell a typo from a real block. Persist nothing on reject; log repeated under-18 attempts against the device, not an account.

Google path. Same 18+ rule. Google returns no birth date, so 4e is a blocking one-field step after the handoff — the account exists but can't browse or post until DOB is recorded. Confirming Google's name and email keeps it reading as step 2 of 2, not a restart.

Storage. Store the date, and store the 18+ declaration as a separate timestamped record (date entered, method, app version). Expose age range to other traders, never the date. Gender is not collected.

Fields. 56 tall, radius 10, fill #F1EFE8, border 1 #E2E0D6. Focused: fill #FAFAF7, border 1.5 #3DBE5A, ring 3 rgba(61,190,90,.16), label #1B4D2B. Error: border 1.5 #C56A4B, label #B0553A, message 12/500 #B0553A. Confirm-password match shows a 18px #1B4D2B check.

Video. Scrim rgba(20,20,15,.28) → .52, raised to .40 → .62 on the rejection screen. Poster frame on first paint, 6–10s muted loop, pause on background and data-saver.
